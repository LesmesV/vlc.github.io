    How to use the workout timer

    1. Add the exercises and durations you want. You can edit each exercise after adding it.
    2. If you want to do the workout again in the future, create an account below using your email and a password.
    3. Give your workout a name and select Save Workout.
    4. Press Start Workout and follow the timer.
